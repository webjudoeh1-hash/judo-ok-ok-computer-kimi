# Diseño de Aplicación Web para Academia de Judo

## Filosofía de Diseño
- **Estilo Visual**: Minimalista japonés con influencias modernas
- **Colores**: Blanco puro (#FFFFFF), negro profundo (#1A1A1A), gris carbón (#2D2D2D), y un acento dorado (#D4AF37) inspirado en el cinturón negro
- **Tipografía**: Títulos en "Playfair Display" (serif elegante) y texto corporal en "Inter" (sans-serif moderna)
- **Espíritu**: Disciplina, respeto y maestría del judo

## Estructura de la Aplicación
1. **Área Pública**: Información general, horarios, técnicas y filosofía del judo
2. **Área Privada**: Sistema de autenticación con dos roles
3. **Panel de Administración**: Gestión completa de usuarios y contenidos
4. **Área de Usuario**: Acceso de solo lectura a contenidos protegidos

## Elementos Visuales
- Hero con imagen de judo dinámico
- Animaciones sutiles de scroll y transiciones
- Efectos de hover elegantes
- Iconografía inspirada en el arte marcial
- Layout limpio y profesional

## Características Técnicas
- Diseño totalmente responsive
- Integración con Supabase para autenticación y base de datos
- Sistema de roles y permisos
- Gestión de contenidos dinámicos
- Preparado para despliegue en Vercel
